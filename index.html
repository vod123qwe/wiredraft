⚡ Połącz Claude Code (MCP)

    
1. W terminalu (w katalogu projektu) dodaj serwer MCP:

    
claude mcp add wiredraft -- npx -y github:vod123qwe/wiredraft

    
…albo ręcznie w .mcp.json:

    
{
  "mcpServers": {
    "wiredraft": {
      "command": "npx",
      "args": ["-y", "github:vod123qwe/wiredraft"]
    }
  }
}

    
2. W Claude Code poproś np. „zrób makietę ekranu logowania". Dostaniesz link do WireDraft (…/#z=…) — otwórz go tutaj, dopieść makietę i wyeksportuj do Figmy.

    
Serwer udostępnia narzędzia create_wireframe (→ link do edytora + podgląd ASCII) oraz render_wireframe. Model obiektów jest zgodny z wiretext.

    
Stały kod projektu (= ten sam pokój Live session): dodaj "env": { "WIREDRAFT_CODE": "WD-XXXXXXXX" } w konfiguracji powyżej (albo arg code per wywołanie). Bez tego każdy link = nowy pokój.
